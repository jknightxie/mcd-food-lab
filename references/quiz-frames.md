# 战力测试题面梗库（50 帧 · 六种喜感来源混编）

## 设计规则

- **喜感来自混编，不靠单一句式**：50 帧分六种来源——毒舌吐槽 / 拟人选秀 /
  场景剧 / 对话体 / 荒诞公文 / 连续剧。反转只是调味，不单独成帧
  （清一色「三段式反转」的教训：第一遍新鲜，第十遍就是填空题模板）
- **一场 3 题从不同来源抽帧**（引擎保证 mode 不重复），拒绝十连抽同一语气
- **每帧都是选择题**：选项由数据槽位生成（{A}/{B}/干扰款/对错）
- **答案数字不进题面**：T2 不给「蛋白 + 价格」成对、每元值不出现、
  T1 不给蛋白克数；价格/合计/找零等情境数字可以出现
- 每帧绑定一个**题型槽位**（见下表）；帧间不依赖同场其他题的内容
  （连续剧的虚构前情提要在帧内自述，不算依赖）
- 揭示语按帧定制语气，数字纪律不变：全部来自实测

## 题型槽位与选项集

| 槽位 | 内容 | 选项集 |
|---|---|---|
| T1 总量陷阱 | {A} vs {B} 谁蛋白多 | {A} / {B} / 一样多 |
| T2 每元蛋白 | {A} vs {B} 每 1 元谁回报高 | {A} / {B} / 一样多 |
| T3 补钙王 | 全店每 1 元补钙最多的是 | 冠军 + 3 干扰款 |
| T4 蛋白王 | 全店每 1 元蛋白最多的是 | 冠军 + 3 干扰款 |
| T5 省热王 | 每 1 元吃到的热量最少的是 | 冠军 + 3 干扰款 |

（{A}/{B} 默认取「每元冠军 vs 价差最大的知名款」，由引擎按实测数据选取；
干扰款从总量榜靠前的真实餐品里出，绝不用不存在的名字。）

## 一、毒舌吐槽（8 帧）——主持人有脾气，答错当场开涮

## 接入引擎的改造要点（2026-10-14 已实现）

1. `quiz.py` 增加 `FRAMES` 注册表：每帧 = （题面模板，绑定题型槽位，
   揭示模板，选项生成规则，mode 标签）——选项由既有逻辑按实测数据产出，
   帧只改题面外壳与语气
2. `build_quiz` 流程不变（先按数据出题，T1/T2 反转对撑不起就换找冠军型），
   实例化后**按题型槽位随机套帧**，同一场 3 题的 mode 不重复、帧不重复
3. 揭示语模板按帧微调语气，但数字与结论句保持统一（来自实测数据）
4. 新帧入库标准：自带明确笑点来源（六选一），缺 mode 的帧不收；
   「三段式反转」不再作为独立帧型，只能作为调味句出现在帧内
